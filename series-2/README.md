# 二者のあいだ

## RELATION ── 二者のあいだに関する考察、全12回

**個々の性能ではなく、あいだを設計する。**

第1クール「[意味の関連性](../README.md)」は、関係を一つのぼやけた塊として扱った。意味は分布であり、関係もまた分布であり、関連は仮説に過ぎず、評価がそれを検証する。第2クールは、その塊をほどく。「関係がある」と一括りにしていたものが、同一・包含・補完・依存・因果・比喩など性質の違う関係の重なりだったことから始め、関係の種類を分けたうえで、関係が何を生み、関係がなかった場合と比べて何が変わるのかを問う。問いはただ一つ、**二者のあいだに「関係がある」と言うとき、それはどの関係で、何を生み、何と比べて価値があるのか**。

毎回の終わりに、同じ一組の例に、その回で手に入れた道具を当てる。AIがコードを生成し、人間がそれをレビューする、という一組である。第1回では「順序・依存・補完」の三語でしか言えなかったものが、最終回には四つの階層で記述され、設計の対象になる。

[第1回から読む](chapters/01-relations-overlap.md) ／ [最終回を読む](chapters/12-designing-relations.md) ／ [付録：関係型・効能型・Entityスキーマ](APPENDIX.md) ／ [連載の設計書](SERIES-DESIGN.md)
