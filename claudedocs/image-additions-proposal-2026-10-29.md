## 0. 今回の見立て

ここまでの図は全て「本文の主張を説明する図」だった。節ごとに棚卸しすると、説明図としての穴は少ない。残っているのは、種類の違う図像である。

1. **連載単位の図像**: 第2クールに表紙がない。第1クールに見取り図がない。トップページに二つの連載の関係を示す図がない。
2. **読者が図を読み解くための凡例**: ぼやけた円、破線、藍と深緑の使い分けなど、図の記法を説明する図が一枚もない。
3. **第1クールで見送った中優先の説明図**: 見取り図、問いの形、関心空間の三つ。
4. **第2クールの共通例で図のない回**: 第2・3・4・11回の「適用」節。
5. **部の冒頭の扉絵**: 部が切り替わったことを示す、ラベルのない象徴図。今はどの回にもない。
6. **付録とガイドの図**: Entity体系の見取り図、七群の地図。

5は性格が違う（説明ではなく区切り）。調整の結果、部の冒頭のみ、既存の図と同じ幾何的な記号、最優先、と決めた。

### 規則

- 置き場所は、副題と冒頭の前後ナビの直後、本文の最初の段落の前。
- 文字を入れない。見出しラベル（`RELEVANCE 05 図5-1` の行）も入れない。本文を読む前に目に入るので、主張を先出ししない。
- 様式は既存の説明図と同じ幾何的な記号に限る。ぼやけた円、線、矢印、箱、破線。人影・鳥・鍋のような具象の形は描かない。
- 大きさは 1200×360。本文幅いっぱい、枠線なし（説明図の枠と区別する）。
- 図番号もキャプションも持たない。ファイル名は `NN-0-opener.svg`。`series.json` の `figures` には載せず、`openers` として別に持つ。

## 8. 実装時に変えるもの

- 表紙・見取り図・関係図・凡例は章の図ではないので、`series.json` の `figures` には載せず、`draw_figures.py` の期待集合に別枠（`extras`）を設ける。検査の「SVG総数」もそれを数える。
- 扉絵は、図の記法規則（`guides/EDITING.md`）に「部の冒頭のみ、文字なし、章の図番号を持たない、`NN-0-opener.svg`、1200×360、枠線なし」を追記する。`series.json` の `parts` に `opener` を持たせ、検査は「各部に扉絵が一枚あり、該当回の本文冒頭で参照されている」ことを確かめる。説明図の検査（番号つきキャプション）は扉絵に適用しない。
- CSS で扉絵（`img.opener`）は枠線・余白・背景なしで表示し、電話幅でも横スクロールにせず全幅で縮小する（文字がないので縮小しても読めなくならない）。
- 凡例の色名は CSS の変数と同じ値（藍 `#5a4fcf`、深緑 `#2f8f83`、橙 `#d0693a`）を使う。
